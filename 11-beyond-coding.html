IDEAS · 它可以幫哪些忙？

不是只有程式：把零散工作變成可交付成果

研究與閱讀

整理你提供的文章、PDF、筆記；歸納不同觀點、列出待查問題、生成讀書會討論題。

生活規劃

依你提供的條件比較旅行方案、排每日行程、整理搬家清單或家庭採買清單。

文件與表格

整理匿名化的 CSV、分類收據、產生月度摘要、把會議筆記轉成行動項目。

創作與學習

設計語言練習、讀書計畫、桌遊規則草稿、活動流程和多種文案版本。

個人小工具

製作待辦清單、習慣追蹤器、菜單產生器或本機可用的單頁 HTML 小工具。

重複工作

為規律且可檢查的檔案整理、命名、格式轉換寫一套可重用流程。

Codex 的具體能力取決於你使用的 App、CLI、IDE、可用工具與權限設定。涉及外部帳戶、購買、寄送或發布時，先確認它是否真的有相應工具，並在執行前檢查。

SCENARIO 01 · TRIP PLANNER

情境一：把旅行靈感變成可執行行程

任務卡

狀況：你有 3 天假期、想帶長輩去台南，手上有幾個景點連結和一份自己存的餐廳清單。想要步調輕鬆、每天不要排太滿，還希望下雨時有備案。

讓 Codex 交付：先讀你提供的資料，整理景點位置與營業資訊的待確認項目，排出鬆散的每日路線，標示移動方式、預留休息時間，並為每天下雨時提出室內備案。

  • 路線是否按地理位置安排，避免一天來回奔波？
  • 營業時間、交通和票價有來源或明確標示待查嗎？
  • 每天是否有足夠休息空間，符合同行者需要？
  • 雨天備案是否真的在附近、而且適合同行成員？

追加限制：「第二天午後可能下雨、全程不開車、每天最多步行 6,000 步。」觀察它如何更新計畫，並指出還需要你提供哪些資訊。

SCENARIO 02 · DIGITAL DECLUTTER

情境二：清理桌面，把散亂檔案變成安心的資料夾

任務卡

狀況：下載資料夾塞滿了 PDF、圖片和文件，你想按用途分類，找到可能重複的檔案，建立一份檔案索引。

安全做法：先複製一份範例資料到練習資料夾，要求 Codex 先列出分類計畫與預計動作，再只做預覽報告；核對無誤後，才讓它整理練習副本。重要原件和個資不要拿來做第一輪測試。

  • 整理前預覽：每個檔案會被如何處理。
  • 保留原始檔、不刪除不確定的項目。
  • 檔案索引可搜尋、可追溯回來源路徑。
  • 執行後產生摘要，列出沒處理和需要人工確認的項目。
記住：檔案操作可能無法輕易復原。以副本試作、讓 Codex 先列計畫、你確認後才執行，是很實用的生活代理流程。
SCENARIO 03 · STUDY COACH

情境三：打造一個會出題的個人學習教練

任務卡

狀況：你正在自學日文、攝影或一門新技能，手上有筆記和想達成的目標。請 Codex 把材料轉成兩週計畫、每天 20 分鐘的小任務、複習卡和每週自我測驗。

讓它像教練：不要一口氣給滿滿教科書；請它每天給一項任務、根據你的回答調整難度，並清楚指出哪些內容來自你的筆記、哪些是它建議你另外查證的。

小測驗：讓個人 AI 教練幫你排學習計畫，最好的下一步是？
MAKE YOUR OWN · 迷你代理實驗

設計一個你自己會想每天使用的小 Agent

挑一件每週都會重複、輸入資料清楚、結果容易核對的小事。想像它像一位可靠的助理：會說明計畫、不確定時先問、交付後列出依據。

靈感抽卡

一週剩菜食材盤點 → 產生晚餐點子 → 避開過敏原 → 列一張採買清單。

會議筆記 → 決議、負責人、期限、尚待回答問題的追蹤表。

桌遊聚會偏好 → 遊戲推薦與活動流程；或個人照片檔名與相簿索引整理。

寫出任務規格

  1. 輸入：你會提供什麼資料？
  2. 目標：它要替你省掉哪一步？
  3. 限制：哪些事絕對不能做或不能猜？
  4. 輸出：你希望拿到什麼格式？
  5. 驗收：怎麼快速確認結果可信又好用？
HUMAN IN THE LOOP · 人要留在流程裡

生活代理好用，關鍵是你仍握著方向盤

保護個人資料

先用虛構或去識別化資料練習。不要隨手提供密碼、完整身分證號、銀行資訊、醫療紀錄或他人的私人訊息。

外部資訊要核實

行程、營業時間、政策、價格與健康資訊可能會變。要求列出來源和待確認事項，重要決策回原始來源查證。

高影響決定由你做

醫療、法律、財務、安全和照護決策不能只交給 AI。讓它協助整理問題與選項，由合格專業人士或你本人判斷。

先預覽再動手

寄信、發文、下單、刪檔、改系統設定等外部或難以復原的動作，先要求草稿或操作計畫，核對後再明確確認。

FINAL TAKEAWAY

畢業趣味挑戰：讓 Codex 幫你省下半小時

本週挑一件低風險、真實會發生的小事，例如整理讀書筆記、比較你提供的旅行候選地、規劃一週晚餐，或把興趣資料做成一頁索引。

  1. 把需求寫成「輸入、目標、限制、輸出、驗收」。
  2. 要求先回覆計畫和未知處；有檔案變更就先做副本或預覽。
  3. 看成果並指出一個不符合期待的地方，觀察它能否根據回饋調整。
  4. 記下省下的時間、需要人工核對的事，以及下次想改進的提示。

完成標準：你得到一項自己真的用得上的成果，知道它如何產生，也清楚哪些判斷仍由自己負責。
