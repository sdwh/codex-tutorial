THE ESSENCE

你定義成功，Codex 推進工作。

Agent 可以讀檔、改程式、執行工具與驗證結果。協作的關鍵，是把每一步連成可檢查的工作循環。

01 / DEFINE

說清目標

提供使用情境、限制與完成條件。

02 / CONTEXT

讀對脈絡

指定檔案、規格、錯誤與專案規則。

03 / EXECUTE

執行與調整

複雜工作先規劃，中途用回饋校正。

04 / VERIFY

檢查交付

看 diff、實際測試與未解決事項。

YOUR FIRST WIN / 15 分鐘起步

先完成一個小而完整的任務。

完整入門練習 →
  1. 開啟自己的 repo，確認 Git 狀態與使用帳號。
  2. 找一個容易重現的小問題，附上相關檔案或錯誤。
  3. 貼上右側任務範本，替換中括號內容。
  4. 檢查 diff 與驗證證據，再決定是否提交。

STUDY TIMER

手動計時，不虛報閱讀時間

進入單元後按「開始計時」。切到其他分頁會暫停累計；可隨時暫停或歸零。

20 小時主課程怎麼安排：10 個必修單元各 2 小時，包含概念閱讀、引導案例、實作、變體挑戰和回顧；另有生活 Agent 與製作案例兩章，共 4 小時加值內容。你需要一個可讀寫的程式專案和 Codex App、CLI 或 IDE 擴充；沒有現成 repo 時，可用單元案例建立練習專案。課程時間是建議實作時間，實際依經驗調整。
